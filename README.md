## ✨ О проекте

Каждое утро бот спрашивает, что вы планируете сделать за день. В течение дня — напоминает о ваших целях и подбадривает. А вечером помогает честно оценить результат: что получилось, а над чем стоит поработать завтра.

Никаких сложных интерфейсов — только чат в Telegram и пара тапов по кнопкам.

## 🚀 Возможности

- 📝 **Планирование целей** — просто перечислите их с новой строки
- ⏰ **4 умных напоминания в день** — по расписанию, без спама
- 💡 **Мотивация и советы** — не даёт забросить цель на полпути
- ✅ **Интерактивный отчёт** — отмечайте статус инлайн-кнопками, без ввода текста
- 📊 **Итоги дня** — что достигнуто, что нет, и почему стоит попробовать снова
- 🗑 **Гибкое управление** — можно убрать цель из списка в любой момент

## 🖥 Команды

| Команда | Что делает |
|:---|:---|
| `/start` | 👋 Запуск бота и знакомство с возможностями |
| `/plan` | 📝 Запланировать цели на сегодня вне расписания |
| `/today` | 📋 Посмотреть текущие цели и их статусы |
| `/remove` | 🗑 Убрать одну или несколько целей из списка |
| `/report` | 📊 Отчитаться о выполнении досрочно |

## ⚡ Быстрый старт

```bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

pip install aiogram APScheduler aiohttp
```

## ⚙️ Настройка

```bash
export BOT_TOKEN="ваш_токен_от_@BotFather"
export BOT_PROXY="socks5://127.0.0.1:10808"   # опционально, если Telegram заблокирован
```

Время рассылок легко поменять под себя — в начале `tracker_bot.py`:

```python
TIME_PLAN      = (8, 0)    # 🌅 утреннее планирование
TIME_MIDDAY    = (12, 0)   # ☀️ напоминание + мотивация
TIME_AFTERNOON = (16, 0)   # 🌇 напоминание + совет
TIME_REPORT    = (20, 0)   # 🌙 вечерний отчёт
```

## ▶️ Запуск

```bash
python tracker_bot.py
```

Для стабильной круглосуточной работы на сервере рекомендуется запускать через **pm2** или **systemd**, чтобы бот автоматически перезапускался при сбоях.
